Hugo Commands

Config Commands

/setup

Description: Run the bot setup process

/logs

Description: Server and bot event logging

Subcommands:

  • error: Channel where bot error logs are sent
    • enable (optional, boolean): Enable error logging?
    • channel (optional, channel): Channel to send error logs
    • mention (optional, boolean): Enable mentions in error logs?
  • chat: Channel where chat logs are sent
    • enable (optional, boolean): Enable chat logging?
    • channel (optional, channel): Channel to send chat logs
    • mention (optional, boolean): Enable mentions in chat logs?
  • general: Channel where all other logs are sent
    • enable (optional, boolean): Enable general logging?
    • channel (optional, channel): Channel to send general logs
    • mention (optional, boolean): Enable mentions in general logs?
  • enable: Enable specific log event type
    • type (optional, string): Event type to enable
  • disable: Disable specific log event type
    • type (optional, string): Event type to disable

/color

Description: Self-assignable color roles sorted by hue

Subcommands:

  • add: Add color to the list
    • name (required, string): Name of the color
    • color (required, string): Hex RGB of the color
  • remove: Remove color from the list
    • name (required, string): Name of the color
  • list: List all colors
  • edit: Edit color in the list
    • name (required, string): Name of the color
    • new-name (optional, string): New name for the color
    • new-color (optional, string): New hex RGB for the color
  • default: Default color for users yet to select one
    • enable (optional, boolean): Enable default color?
    • name (optional, string): Name of the color
  • create: Create color roles
    • target (required, role): Role above which color roles will be placed
    • prefix (optional, string): Prefix for the roles
    • suffix (optional, string): Suffix for the roles
  • post: Post color role selection embeds
    • channel (required, channel): Channel to post color selection in
  • reset: Reset color list to default colors
  • custom: Configure custom color role settings
    • enable (optional, boolean): Enable custom color roles?
    • prefix (optional, string): Prefix for custom color roles
    • suffix (optional, string): Suffix for custom color roles

/custom

Description: Create a custom color role with any hex color

Options:

  • hex (required, string): Hex color code (e.g. FF0000 or #FF0000)

Automation Commands

/autothread

Description: Automatic threads on new messages

Subcommands:

  • settings: Automatic thread settings
    • enable (optional, boolean): Enable automatic threads?
    • title (optional, string): Title of the threads
    • message (optional, string): Message to send in new threads
    • message-enable (optional, boolean): Enable sending the message?
  • add: Add automatic thread channel
    • channel (required, channel): Channel to add
    • on-text (optional, string): Action for text-only messages — thread, delete, or ignore (default: delete)
    • on-media (optional, string): Action for media/link messages — thread, delete, or ignore (default: thread)
    • title (optional, string): Thread title override for this channel (default: global)
    • message (optional, string): Thread message override for this channel (default: global)
    • message-enable (optional, boolean): Enable thread message for this channel? (default: global)
  • edit: Edit per-channel autothread settings
    • channel (required, channel): Channel to edit
    • on-text (optional, string): Action for text-only messages — thread, delete, or ignore
    • on-media (optional, string): Action for media/link messages — thread, delete, or ignore
    • title (optional, string): Thread title override (use "reset" to clear back to global)
    • message (optional, string): Thread message override (use "reset" to clear back to global)
    • message-enable (optional, boolean): Enable thread message for this channel?
  • remove: Remove automatic thread channel
    • channel (required, channel): Channel to remove
  • list: List automatic thread channels
    • channel (optional, channel): View settings for a specific channel

/autoresponse

Description: Automatic responses to message triggers

Subcommands:

  • settings: Autoresponse settings
    • enable (optional, boolean): Enable automatic responses?
    • cooldown (optional, integer): Cooldown between responses in seconds
  • add: Add an autoresponse
    • title (required, string): Name for this autoresponse
    • trigger (required, string): Text that triggers the response
    • response (optional, string): The response to send
    • reply (optional, boolean): Reply to the trigger message? (default: false)
    • delete (optional, boolean): Delete the trigger message? (default: false)
    • channel (optional, channel): Only trigger in this channel
    • channel-enable (optional, boolean): Limit to selected channel? (default: false)
    • regex (optional, boolean): Use trigger as a regex pattern? (default: false)
    • case-sensitive (optional, boolean): Case-sensitive trigger? (default: false)
    • cooldown (optional, integer): Cooldown for this response in seconds (default: global cooldown)
  • edit: Edit an existing autoresponse
    • title (required, string): Name of the autoresponse to edit
    • new-title (optional, string): New name for this autoresponse
    • trigger (optional, string): New trigger text
    • response (optional, string): New response text
    • reply (optional, boolean): Reply to the trigger message?
    • delete (optional, boolean): Delete the trigger message?
    • channel (optional, channel): Only trigger in this channel
    • channel-enable (optional, boolean): Limit to selected channel?
    • regex (optional, boolean): Use trigger as a regex pattern?
    • case-sensitive (optional, boolean): Case-sensitive trigger?
    • cooldown (optional, integer): Cooldown for this response in seconds
  • remove: Remove an autoresponse
    • title (required, string): Name of the autoresponse to remove
  • list: List all autoresponses
    • title (optional, string): View a specific autoresponse by title

/reactionrole

Description: Manage reaction roles

Subcommands:

  • add: Add a reaction role to a message
    • message (required, string): Message ID or link to attach the reaction role to
    • emoji (required, string): Emoji to react with
    • role (required, role): Role to grant when reacted
    • mode (optional, string): Role mode for this message — normal or exclusive (default: normal)
  • remove: Remove a reaction role from a message
    • message (required, string): Message ID or link
    • emoji (required, string): Emoji to remove
  • list: List all active reaction role bindings
  • settings: Enable or disable reaction roles

  • repair: Re-add bot reactions to all bound messages (fixes missing reactions)

/qotd

Description: Question of the Day

Subcommands:

  • settings: Configure QOTD settings
    • enable (optional, boolean): Enable automatic Question of the Day?
    • channel (optional, channel): Channel to post questions in
    • interval (optional, string): Time between questions (e.g. 24h, 1d, 12h30m)
    • message (optional, string): Custom text to send with the question
    • message-enable (optional, boolean): Send the custom message with each question?
    • thread (optional, boolean): Auto-create a thread for each question?
    • thread-title (optional, string): Thread title template ({date}, {time} placeholders)
    • thread-message (optional, string): Message to send in the auto-created thread
    • thread-message-enable (optional, boolean): Send the thread message in each thread?
    • embed (optional, boolean): Send the question as an embed?
    • embed-title (optional, string): Custom embed title
    • embed-title-enable (optional, boolean): Show the embed title?
    • embed-footer-enable (optional, boolean): Show the embed footer?
    • embed-footer (optional, string): Footer text on the embed
  • post: Post the next queued question now
  • add: Add a question directly to the approved queue
    • question (required, string): The question to add
  • skip: View upcoming questions and skip any
    • duration (optional, string): Temporary skip duration (e.g. 2d, 12h, 1d6h). Omit for permanent skip.
  • queue: View the approved question queue
    • page (optional, integer): Page number
  • remove: Remove a question from the approved queue
    • number (required, integer): Question number to remove
  • move: Move a question to a different position in the approved queue
    • from (required, integer): Current position number of the question
    • to (required, integer): New position number for the question
  • bulk-add: Add multiple questions to the approved queue at once
    • questions (required, string): Pipe-separated questions (e.g. Question one? | Question two?)
  • shuffle: Toggle between sequential and random question order
  • preview: Preview what the next post will look like
  • history: Show recently posted questions
  • clear: Clear a queue or list
    • target (required, string): What to clear — approved, skiplist, pending, or history
  • reset: Reset the question index back to 0
    • index (optional, integer): Set the question index to a specific number
  • next: Set when the next question should be posted
    • in (optional, string): Time from now (e.g. 2h, 30m, 1d12h). Omit to view current schedule.

    • enable (optional, boolean): Enable command?

    • channel (optional, channel): Channel for usage
    • channel-enable (optional, boolean): Limit to selected channel?
  • remindme: Manage /remindme and /reminders command settings
    • enable (optional, boolean): Enable command?

    • channel-enable (optional, boolean): Limit to selected channel?
