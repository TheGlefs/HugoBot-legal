Hugo Commands

Config Commands

/setup

Description: Run the bot setup process

/logs

Description: Important server logging settings

Subcommands:

  • error: The error log channel where bot error logs are sent
    • enable (optional, boolean): Enable error logging?
    • channel (optional, channel): The channel to send error logs in
    • mention (optional, boolean): Enable mentions in error logs?
  • chat: The chat log channel where chat logs are sent
    • enable (optional, boolean): Enable chat logging?
    • channel (optional, channel): The channel to send chat logs in
    • mention (optional, boolean): Enable mentions in chat logs?
  • general: The general log channel where all other logs are sent
    • enable (optional, boolean): Enable general logging?
    • channel (optional, channel): The channel to send general logs in
    • mention (optional, boolean): Enable mentions in general logs?
  • enable: Enable a specific log event type
    • type (optional, string): The event type to enable
  • disable: Disable a specific log event type
    • type (optional, string): The event type to disable

/color

Description: Create, manage and post color roles

Subcommands:

  • create: Create color roles, placing them above a selected role
    • target (required, role): The role above which the color roles will be placed
    • prefix (optional, string): Prefix for color roles
    • suffix (optional, string): Suffix for color roles
  • post: Post color role selection embeds
    • channel (required, channel): The channel to post the color selection in
  • default: The default color granted to users who have not selected a color
    • enable (optional, boolean): Enable use of the default color?
    • name (optional, string): The name of the color to grant
  • add: Add a color to the color list, automatically sorted by hue before saving
    • name (required, string): The name of the color to add
    • color (required, string): The rgb hex of the color to add
  • remove: Remove a color from the color list
    • name (required, string): The name of the color to remove
  • edit: Edit a color in the color list, automatically sorted by hue before saving
    • name (required, string): The name of the color to edit
    • new-name (optional, string): The new name for the color
    • new-color (optional, string): The new rgb hex for the color
  • list: List all colors in the color list
  • reset: Reset the color list to the default colors

/group

Description: Manage user groups that automatically grant channel permissions

Subcommands:

  • create: Create a user group that automatically grant channel permissions
    • group (required, string): The name of the user group
  • delete: Delete a user group
    • group (required, string): The name of the user group
    • revoke (optional, boolean): Revoke access to all the channels in the group for all members?
  • list: List all users and channels in a user group
    • group (optional, string): The name of the user group. Leave blank to list all groups.
  • restore: Should group membership be restored when a user rejoins?
    • group (optional, string): The name of the user group
    • enable (optional, boolean): Enable restoring group membership?
  • add-member: Add a member to a user group
    • group (required, string): The name of the user group
    • member (required, user): The member to add to the user group
  • add-channel: Add a channel to a user group all members will get permissions for
    • group (required, string): The name of the user group
    • channel (required, channel): The channel that all group members will get permissions for
  • add-channel-viewers: Add all users who can view a channel to a user group
    • group (required, string): The name of the user group
    • channel (required, channel): The channel to add all users who can view to the user group
  • add-role: Add all users with a role to a user group
    • group (required, string): The name of the user group
    • role (required, role): The role to add all users with to the user group
  • remove-member: Remove a member from a user group
    • group (required, string): The name of the user group
    • member (required, string): The member to remove from the user group
    • revoke (optional, boolean): Revoke access to all the channels in the group?
    • inform (optional, boolean): Inform the member that they have been removed from the group?
  • remove-channel: Remove a channel from a user group
    • group (required, string): The name of the user group
    • channel (required, channel): The channel to remove from the user group
    • revoke (optional, boolean): Revoke access to the channel from all group members?
  • remove-role: Remove a role from user a group
    • group (required, string): The name of the user group
    • role (required, role): The role to remove from the user group
  • edit-permissions: Edit the automatic channel permissions for a user group
    • group (required, string): The name of the user group
    • permission (required, string): The permission to edit
    • enable (required, boolean): Enable or disable the permission
    • mod (optional, boolean): Is this a permission for mods only?
  • list-permissions: List the automatic channel permissions for a user group
    • group (required, string): The name of the user group
  • refresh-permissions: Refresh channel permissions for all members of a user group
    • group (required, string): The name of the user group
  • copy-permissions: Copy channel permissions from one user group to another
    • source (required, string): The name of the user group to copy permissions from
    • recipient (required, string): The name of the user group to copy permissions to

Verification Commands

/role

Description: Important server roles

Subcommands:

  • verified: Configure the role that counts as being verified
    • enable (optional, boolean): Enable use of the verified role?
    • role (optional, role): The role that counts as being verified
  • unverified: Configure the role that counts as being unverified
    • enable (optional, boolean): Enable use of the unverified role?
    • role (optional, role): The role that counts as being unverified
  • moderator: Configure the role that counts as being a moderator
    • enable (optional, boolean): Enable use of the moderator role?
    • role (optional, role): The role that counts as being a moderator

/captcha

Description: Manage captcha verification

Subcommands:

  • post: Post the captcha verification embed
    • channel (required, channel): Channel to post the captcha in
    • title (optional, string): The title of the captcha
    • description (optional, string): The description of the captcha
  • settings: Configure captcha settings
    • fail-enable (optional, boolean): Enable max verification attempts?
    • fail-max (optional, integer): Max verification attempts before kick/ban
    • fail-ban (optional, boolean): Ban users who fail verification instead of kicking?
    • fail-reason (optional, string): Reason for kick/ban after failing verification
    • time-enable (optional, boolean): Enable time limit?
    • time-limit (optional, integer): Time limit in hours before automatic kick/ban
    • time-ban (optional, boolean): Ban users after time limit instead of kicking?
    • time-reason (optional, string): Reason for kick/ban after time limit

Moderation Commands

/rolekick

Description: Roles that get instantly kicked

Subcommands:

  • settings: Enable forbidden roles and edit ban/kick mode and reason
    • enable (optional, boolean): Enable kicking users with forbidden roles?
    • ban (optional, boolean): Ban instead of kick?
    • reason (optional, string): The reason provided when kicking users
      {roletag}, {rolename}
  • add: Add a role to the list of roles that instantly get kicked
    • role (required, role): The role to add to the list
    • retroactive (optional, boolean): Apply to existing members with this role?
  • remove: Remove a role from the list of roles that instantly get kicked
    • role (required, role): The role to remove from the list
  • list: List all roles that get instantly kicked

/agekick

Description: Automatically kick joining users based on account age

Options:

  • enable (optional, boolean): Enable kicking new accounts?
  • days (optional, integer): The minimum account age in days
  • reason (optional, string): The reason provided when kicking users
  • ban (optional, boolean): Ban instead of kick?
  • retroactive (optional, boolean): Apply to users who joined before enabling the feature?

/purge

Description: Delete all messages from a specific user

Options:

  • target (required, user): The user whose messages you want to delete

Description: User arrival and departure message settings

Subcommands:

  • join: Announce when users join the server

    • channel (optional, channel): The channel to send join messages in
  • leave: Announce when users leave the server
    • enable (optional, boolean): Enable announcing when users leave?
    • message (optional, string): Message to send when users leave
      {tag}, {name}, {user}
    • channel (optional, channel): The channel to send leave messages in
  • leave-verified: Extra announcement when verified users leave
    • enable (optional, boolean): Enable announcing when verified users leave?
    • message (optional, string): Message to send when verified users leave
      {tag}, {name}, {user}
    • channel (optional, channel): The channel to send verified user leave messages in
  • rejoin: Announce when users rejoin the server
    • enable (optional, boolean): Enable announcing when users rejoin?
    • same-user (optional, string): Message to send when users rejoin
      {tag}, {name}, {user}
    • name-change (optional, string): Message for users who changed their username
      {tag}, {name}, {user}, {oldname}, {olduser}
    • channel (optional, channel): The channel to send rejoin messages in
  • rejoin-verified: Extra announcement when verified users rejoin
    • enable (optional, boolean): Enable announcing when verified users rejoin?
    • same-user (optional, string): Message to send when verified users rejoin
      {tag}, {name}, {user}
    • name-change (optional, string): Message for verified users who changed their username
      {tag}, {name}, {user}, {oldname}, {olduser}
    • channel (optional, channel): The channel to send verified user rejoin messages in
  • ban: Announce when users are banned from the server
    • enable (optional, boolean): Enable announcing when users are banned?
    • message (optional, string): Message to send when users are banned
      {tag}, {name}, {user}, {modtag}, {modname}, {moduser}, {reason}
    • channel (optional, channel): The channel to send ban messages in
  • ban-verified: Extra announcement when verified users are banned
    • enable (optional, boolean): Enable announcing when verified users are banned?
    • message (optional, string): Message to send when verified users are banned
      {tag}, {name}, {user}, {modtag}, {modname}, {moduser}, {reason}
    • channel (optional, channel): The channel to send verified user ban messages in
  • unban: Announce when users are unbanned from the server
    • enable (optional, boolean): Enable announcing when users are unbanned?
    • message (optional, string): Message to send when users are unbanned
      {tag}, {name}, {user}, {modtag}, {modname}, {moduser}, {reason}
    • channel (optional, channel): The channel to send unban messages in
  • unban-verified: Extra announcement when verified users are unbanned
    • enable (optional, boolean): Enable announcing when verified users are unbanned?
    • message (optional, string): Message to send when verified users are unbanned
      {tag}, {name}, {user}, {modtag}, {modname}, {moduser}, {reason}
    • channel (optional, channel): The channel to send verified user unban messages in
  • kick: Announce when users are kicked from the server
    • enable (optional, boolean): Enable announcing when users are kicked?
    • message (optional, string): Message to send when users are kicked
      {tag}, {name}, {user}, {modtag}, {modname}, {moduser}, {reason}
    • channel (optional, channel): The channel to send kick messages in
  • kick-verified: Extra announcement when verified users are kicked
    • enable (optional, boolean): Enable announcing when verified users are kicked?
    • message (optional, string): Message to send when verified users are kicked
      {tag}, {name}, {user}, {modtag}, {modname}, {moduser}, {reason}
    • channel (optional, channel): The channel to send verified user kick messages in
  • timeout: Announce when users are timed out
    • enable (optional, boolean): Enable announcing when users are timed out?
    • applied (optional, string): Message to send when timeouts are applied
      {tag}, {name}, {user}, {modtag}, {modname}, {moduser}, {reason}, {expiresat}, {expiresin}
    • removed (optional, string): Message to send when timeouts are removed
      {tag}, {name}, {user}, {modtag}, {modname}, {moduser}
    • expired (optional, string): Message to send when timeouts expire
      {tag}, {name}, {user}
    • channel (optional, channel): The channel to send timeout messages in
  • timeout-verified: Extra announcement when verified users are timed out
    • enable (optional, boolean): Enable announcing when verified users are timed out?
    • applied (optional, string): Message to send when verified users timeouts are applied
      {tag}, {name}, {user}, {modtag}, {modname}, {moduser}, {reason}, {expiresat}, {expiresin}
    • removed (optional, string): Message to send when verified users timeouts are removed
      {tag}, {name}, {user}, {modtag}, {modname}, {moduser}

      {tag}, {name}, {user}

Leveling Commands

/xp

Description: Chat XP/level system

Subcommands:

  • settings: Enable the chat XP/level system and edit cooldown and min/max XP
    • enable (optional, boolean): Enable chat XP/level system?
    • cooldown (optional, integer): Cooldown period for XP gain in ms (1000ms = 1s)
    • min (optional, integer): Minimum XP per message based on message length
    • max (optional, integer): Maximum XP per message based on message length
  • level-up: Enable and edit message sent when a user reaches a new level
    • enable (optional, boolean): Enable level up messages?
    • message (optional, string): Message for new level notification
      {tag}, {name}, {user}, {level}, {xp}, {xpneed}, {xpmiss}
    • channel (optional, channel): Channel for level up messages
    • channel-enable (optional, boolean): Limit level up messages to the selected channel?
  • level-cmd: Enable and edit response message for the /level command
    • enable (optional, boolean): Enable /level command?
    • message (optional, string): Response message for /level
      {tag}, {name}, {user}, {level}, {xp}, {xpneed}, {xpmiss}
    • channel (optional, channel): Channel for /level command usage
    • channel-enable (optional, boolean): Limit /level command usage to the selected channel?
  • rank-cmd: Enable and edit response message for the /rank command
    • enable (optional, boolean): Enable /rank command?
    • message (optional, string): Response message for /rank
      {tag}, {user}, {name}, {level}, {xp}, {xpneed}, {xpmiss}, {rank}, {members}
    • channel (optional, channel): Channel for /rank command usage
    • channel-enable (optional, boolean): Limit /rank command usage to the selected channel?
