Hugo Commands

Config Commands

/setup

Description: Run the bot setup process

/settings

Description: Bot settings like resolving channels by name and timezone

Options:

  • name (optional, string): Bot nickname for this server or "reset"
  • avatar (optional, string): Bot avatar image URL (PNG/JPEG/GIF/WebP) or "reset"
  • banner (optional, string): Bot banner image URL (PNG/JPEG/GIF/WebP) or "reset"
  • resolve-by-name (optional, boolean): Find channels/roles by name when IDs are invalid?
  • delete-threads (optional, boolean): Delete threads when their starting message is deleted?
  • keep-verified (optional, boolean): Keep verified status when a verified user rejoins?
  • timezone (optional, string): IANA timezone for timestamps (e.g. America/New_York)
  • locale (optional, string): BCP 47 locale for date/number formatting (e.g. en-US)
  • thread-archive-duration (optional, integer): Default auto-archive duration for threads the bot creates

/logs

Description: Configure error, chat, and general log channels

Subcommands:

  • error: Error log channel
    • enable (optional, boolean): Enable error logging?
    • channel (optional, channel): Channel to send error logs
  • chat: Chat log channel
    • enable (optional, boolean): Enable chat logging?
    • channel (optional, channel): Channel to send chat logs
  • general: General log channel
    • enable (optional, boolean): Enable general logging?
    • channel (optional, channel): Channel to send general logs
  • enable: Enable a log event type
    • type (optional, string): Event type to enable
  • disable: Disable a log event type
    • type (optional, string): Event type to disable
  • mention: Toggle role mentions in all logs
    • enable (optional, boolean): Enable role mentions in logs?

Colors Commands

/color

Description: Self-assignable color roles sorted by hue

Subcommands:

  • add: Add color to the list
    • name (required, string): Name of the color
    • color (required, string): Hex RGB of the color
  • remove: Remove color from the list
    • name (required, string): Name of the color
  • list: List all colors
  • edit: Edit color in the list
    • name (required, string): Name of the color
    • new-name (optional, string): New color name
    • new-color (optional, string): New hex RGB
  • default: Default color for users yet to select one
    • enable (optional, boolean): Enable default color?
    • name (optional, string): Name of the color
  • remember: Restore color roles on rejoin
    • enable (optional, boolean): Remember color roles on rejoin?
  • create: Create color roles
    • target (required, role): Color role anchor
    • prefix (optional, string): Prefix for the roles
    • suffix (optional, string): Suffix for the roles
  • post: Post color role selection embeds
    • channel (required, channel): Color selection channel
  • reset: Reset to default colors
  • flair: /flair settings
    • enable (optional, boolean): Enable /flair?
    • cooldown (optional, integer): Cooldown (seconds)
    • target (optional, role): Flair role anchor
    • mod-target (optional, role): Mod flair role anchor
    • remember (optional, boolean): Recreate on rejoin?
    • allow-title (optional, boolean): Custom role name?
    • allow-icon (optional, boolean): Custom role icon?
    • allow-gradient (optional, boolean): Gradient color?
    • min-level-chat (optional, integer): Min chat level (0 = none)
    • min-level-voice (optional, integer): Min voice level (0 = none)
    • booster-only (optional, boolean): Booster only?

/flair

Description: Create a personal role with custom color and/or icon

Options:

  • title (optional, string): Role name or "clear" or "delete"
  • hex (optional, string): Hex color (e.g. FF0000) or "clear" or "delete"
  • hex2 (optional, string): Second hex color for gradient (e.g. 00FF00) or "clear" or "delete"
  • link (optional, string): Icon URL (PNG/JPEG/WebP) or "clear" or "delete"
