Hugo Commands

Config Commands

/setup

Description: Run the bot setup process

/logs

Description: Server and bot event logging

Subcommands:

  • error: Channel where bot error logs are sent
    • enable (optional, boolean): Enable error logging?
    • channel (optional, channel): Channel to send error logs
    • mention (optional, boolean): Enable mentions in error logs?
  • chat: Channel where chat logs are sent
    • enable (optional, boolean): Enable chat logging?
    • channel (optional, channel): Channel to send chat logs
    • mention (optional, boolean): Enable mentions in chat logs?
  • general: Channel where all other logs are sent
    • enable (optional, boolean): Enable general logging?
    • channel (optional, channel): Channel to send general logs
    • mention (optional, boolean): Enable mentions in general logs?
  • enable: Enable specific log event type
    • type (optional, string): Event type to enable
  • disable: Disable specific log event type
    • type (optional, string): Event type to disable

/color

Description: Self-assignable color roles sorted by hue

Subcommands:

  • add: Add color to the list
    • name (required, string): Name of the color
    • color (required, string): Hex RGB of the color
  • remove: Remove color from the list
    • name (required, string): Name of the color
  • list: List all colors
  • edit: Edit color in the list
    • name (required, string): Name of the color
    • new-name (optional, string): New name for the color
    • new-color (optional, string): New hex RGB for the color
  • default: Default color for users yet to select one
    • enable (optional, boolean): Enable default color?
    • name (optional, string): Name of the color
  • create: Create color roles
    • target (required, role): Role above which color roles will be placed
    • prefix (optional, string): Prefix for the roles
    • suffix (optional, string): Suffix for the roles
  • post: Post color role selection embeds
    • channel (required, channel): Channel to post color selection in
  • reset: Reset color list to default colors
  • custom: Configure custom color role settings
    • enable (optional, boolean): Enable custom color roles?
    • prefix (optional, string): Prefix for custom color roles
    • suffix (optional, string): Suffix for custom color roles

/custom

Description: Create a custom color role with any hex color

Options:

  • hex (required, string): Hex color code (e.g. FF0000 or #FF0000)

/captcha

Description: Captcha verification

Subcommands:

  • post: Post captcha verification embed
    • channel (required, channel): Channel to post the captcha in
    • title (optional, string): Title of the captcha
    • description (optional, string): Description of the captcha
  • settings: Max attempts and time limit
    • fail-enable (optional, boolean): Enable max verification attempts?
    • fail-max (optional, integer): Max verification attempts before kick
    • fail-ban (optional, boolean): Ban users who fail verification instead of kicking?
    • fail-reason (optional, string): Reason for kick after max attempts
    • time-enable (optional, boolean): Enable time limit?
    • time-limit (optional, integer): Time limit in hours before automatic kick
    • time-ban (optional, boolean): Ban users after time limit instead of kicking?
    • time-reason (optional, string): Reason for kick after time limit

Automation Commands

/autothread

Description: Automatic threads on new messages

Subcommands:

  • settings: Automatic thread settings
    • enable (optional, boolean): Enable automatic threads?
    • title (optional, string): Title of the threads
    • message (optional, string): Message to send in new threads
    • message-enable (optional, boolean): Enable sending the message?
  • add: Add automatic thread channel
    • channel (required, channel): Channel to add
  • remove: Remove automatic thread channel
    • channel (required, channel): Channel to remove
  • list: List automatic thread channels

/message

Description: User arrival and departure messages

Subcommands:

  • join: Announce when users join the server
    • enable (optional, boolean): Enable announcing when users join?
    • message (optional, string): Message to send when users join
    • channel (optional, channel): Channel to send join messages in
  • leave: Announce when users leave the server
    • enable (optional, boolean): Enable announcing when users leave?
    • message (optional, string): Message to send when users leave
    • channel (optional, channel): Channel to send leave messages in
  • leave-verified: Extra announcement when verified users leave
    • enable (optional, boolean): Enable extra announcement when verified users leave?
    • message (optional, string): Message to send when verified users leave
    • channel (optional, channel): Channel to send verified leave messages in
  • rejoin: Announce when users rejoin the server
    • enable (optional, boolean): Enable announcing
    • same-user (optional, string): Message to send when users rejoin
    • name-change (optional, string): Message for users who changed their username
    • channel (optional, channel): Channel to send rejoin messages in
  • rejoin-verified: Extra announcement when verified users rejoin
    • enable (optional, boolean): Enable extra announcement when verified users rejoin?
    • same-user (optional, string): Message to send when verified users rejoin
    • name-change (optional, string): Message for verified users who changed their username
    • channel (optional, channel): Channel to send verified rejoin messages in
  • ban: Announce when users are banned from the server
    • enable (optional, boolean): Enable announcing
    • message (optional, string): Message to send when users are banned
    • channel (optional, channel): Channel to send ban messages in
  • ban-verified: Extra announcement when verified users are banned
    • enable (optional, boolean): Enable extra announcement when verified users are banned?
    • message (optional, string): Message to send when verified users are banned
    • channel (optional, channel): Channel to send verified ban messages in
  • unban: Announce when users are unbanned from the server
    • enable (optional, boolean): Enable announcing
    • message (optional, string): Message to send when users are unbanned
    • channel (optional, channel): Channel to send unban messages in
  • unban-verified: Extra announcement when verified users are unbanned
    • enable (optional, boolean): Enable extra announcement when verified users are unbanned?
    • message (optional, string): Message to send when verified users are unbanned
    • channel (optional, channel): Channel to send verified unban messages in
  • kick: Announce when users are kicked from the server
    • enable (optional, boolean): Enable announcing
    • message (optional, string): Message to send when users are kicked
    • channel (optional, channel): Channel to send kick messages in
  • kick-verified: Extra announcement when verified users are kicked
    • enable (optional, boolean): Enable extra announcement when verified users are kicked?
    • message (optional, string): Message to send when verified users are kicked
    • channel (optional, channel): Channel to send verified kick messages in
  • timeout: Announce when users are timed out
    • enable (optional, boolean): Enable announcing
    • applied (optional, string): Message to send when timeouts are applied
    • removed (optional, string): Message to send when timeouts are removed
    • expired (optional, string): Message to send when timeouts expire
    • channel (optional, channel): Channel to send messages in
  • timeout-verified: Extra announcement when verified users are timed out
    • enable (optional, boolean): Enable extra announcement when verified users are timed out?
    • applied (optional, string): Message to send when verified users timeouts are applied
    • removed (optional, string): Message to send when verified users timeouts are removed
    • expired (optional, string): Message to send when verified users timeouts expire
    • channel (optional, channel): Channel to send verified timeout messages in
  • verified: Announce when users become verified
    • enable (optional, boolean): Enable announcing when users become verified?
    • message (optional, string): Message to send when users become verified
    • channel (optional, channel): Channel to send verified messages in
  • verified-secondary: Extra announcement when users become verified
    • enable (optional, boolean): Enable extra announcement when users become verified?
    • message (optional, string): Secondary message to send when users become verified
    • channel (optional, channel): Channel to send secondary verified messages in
  • jail: Announce when users are sent to or released from jail
    • enable (optional, boolean): Enable announcing when users are sent to jail?
    • applied (optional, string): Message to send when users are sent to jail
    • removed (optional, string): Message to send when users are released from jail
    • channel (optional, channel): Channel to send jail messages in
  • jail-verified: Extra announcement when verified users are sent to or released from jail
    • enable (optional, boolean): Enable extra announcement when verified users are sent to jail?
    • applied (optional, string): Message to send when verified users are sent to jail
    • removed (optional, string): Message to send when verified users are released from jail
    • channel (optional, channel): Channel to send verified jail messages in

/rolekick

    • ban (optional, boolean): Ban instead of kick?

    • role (required, role): Role to add
    • retroactive (optional, boolean): Apply to existing members with the role?

Description: Kick users with new accounts

Options:

  • enable (optional, boolean): Enable kicking new accounts?
  • days (optional, integer): Minimum account age in days
  • reason (optional, string): Reason provided when kicking users
  • ban (optional, boolean): Ban instead of kick?
  • retroactive (optional, boolean): Apply to users who joined before enabling?

/group

Description: User groups that grant channel permissions

Subcommands:

  • create: Create user group
    • group (required, string): Name of the user group
  • delete: Delete user group
    • group (required, string): Name of the user group
    • revoke (optional, boolean): Revoke access to all channels for all members?
  • list: List all users and channels in user group
    • group (required, string): Name of the user group
  • restore: Restore group membership when users rejoin?
    • group (required, string): Name of the user group
    • enable (optional, boolean): Enable restoring group membership?
  • add-member: Add member to user group
    • group (required, string): Name of the user group
    • member (required, user): Member to add
  • add-channel: Add channel to user group
    • group (required, string): Name of the user group
    • channel (required, channel): Channel to add
  • add-channel-viewers: Add all users who can view channel to user group
    • group (required, string): Name of the user group
    • channel (required, channel): Channel to add all users who can view
  • add-role: Add all users with role to user group
    • group (required, string): Name of the user group
    • role (required, role): Role to add all users with
  • remove-member: Remove member from user group
    • group (required, string): Name of the user group
    • member (required, user): Member to remove
    • revoke (optional, boolean): Revoke access to all channels in the group?
    • inform (optional, boolean): Inform the member that they have been removed?
  • remove-channel: Remove channel from user group
    • group (required, string): Name of the user group
    • channel (required, channel): Channel to remove
    • revoke (optional, boolean): Revoke access for all group members?
  • remove-role: Remove role from a user group
    • group (required, string): Name of the user group
    • role (required, role): Role to remove
  • edit-permissions: Edit channel permissions for user group
    • group (required, string): Name of the user group
    • permission (required, string): Permission to edit
    • enable (required, boolean): Enable or disable?
    • mod (optional, boolean): Permission for mods only?
  • list-permissions: List channel permissions for user group
    • group (required, string): Name of the user group
  • refresh-permissions: Update channel permissions for all members of user group
    • group (required, string): Name of the user group
  • copy-permissions: Copy channel permissions from one user group to another
    • source (required, string): Name of the source group
    • recipient (required, string): Name of the recipient group

Leveling Commands

/xp

Description: Chat XP/level system

Subcommands:

  • settings: Chat XP/level system settings
    • enable (optional, boolean): Enable chat XP/level?
    • cooldown (optional, integer): Cooldown for XP gain in ms
    • min (optional, integer): Minimum XP per message based on length
    • max (optional, integer): Maximum XP per message based on length
  • advance: Message when users level up
    • enable (optional, boolean): Enable level up message?
    • message (optional, string): Level up message
      {tag}, {name}, {user}, {level}, {xp}, {xpneed}, {xpmiss}
    • channel (optional, channel): Channel for level up message
    • channel-enable (optional, boolean): Limit message to selected channel?
  • level: Response message for /level command
    • enable (optional, boolean): Enable /level command?
    • message (optional, string): Response message for /level
      {tag}, {name}, {user}, {level}, {xp}, {xpneed}, {xpmiss}
    • channel (optional, channel): Channel for /level usage
    • channel-enable (optional, boolean): Limit /level to selected channel?
  • rank: Response message for /rank command
    • enable (optional, boolean): Enable /rank command?
    • message (optional, string): Response message for /rank
      {tag}, {user}, {name}, {level}, {xp}, {xpneed}, {xpmiss}, {rank}, {members}
    • channel (optional, channel): Channel for /rank usage
    • channel-enable (optional, boolean): Limit /rank to selected channel?
